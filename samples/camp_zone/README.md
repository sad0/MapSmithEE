# Camp: playable area

The example map "Camp" built for the game: SQCAMP (day) and SQCAMPN (night) with their PVRZ pages, walls, search,
height and light maps. It is the SadoQoL rest camp (SQCAMP.ARE expects SadoQoL's priest and merchant creatures,
M_SQ0CMP.lua is SadoQoL's camp spots). To look at it without SadoQoL, open it in
MapSmithEE or rebuild the map with Render area as a generic area.
